JK 正反器 (JK Flip-Flop)

萬用型序向記憶元件，改良自 SR 正反器，當 $J=1, K=1$ 時具備將狀態反轉 (Toggle) 的特性，廣泛應用於同步計數器設計。

📊 JK 正反器特性表 (高亮當前預備動作)

JKCLK下一狀態 Q(t+1)工作模式
00↑Q(t)保持不變 (Hold)
01↑0重置清零 (Reset)
10↑1設定為一 (Set)
11↑Q'(t)反轉狀態 (Toggle)

💻 Verilog HDL 硬體描述語言實作

jk_flipflop.v 
module jk_flipflop (
    input  wire clk, rst_n, J, K,
    output reg  Q
);
    always @(posedge clk or negedge rst_n) begin
        if (!rst_n)
            Q <= 1'b0;
        else begin
            case ({J, K})
                2'b00: Q <= Q;      // Hold
                2'b01: Q <= 1'b0;   // Reset
                2'b10: Q <= 1'b1;   // Set
                2'b11: Q <= ~Q;     // Toggle
            endcase
        end
    end
endmodule
