4對1 多工器 (4-to-1 Multiplexer)

俗稱「資料選擇器 (Data Selector)」，根據選擇線 $S_1, S_0$ 的二進位數值，決定將哪一個輸入通道 ($D_0 \sim D_3$) 的訊號傳遞至輸出端 $Y$。

💻 Verilog HDL 硬體描述語言實作

mux_4to1.v 
module mux_4to1 (
    input  wire [3:0] D,
    input  wire [1:0] S,
    output reg        Y
);
    always @(*) begin
        case (S)
            2'b00: Y = D[0];
            2'b01: Y = D[1];
            2'b10: Y = D[2];
            2'b11: Y = D[3];
        endcase
    end
endmodule
